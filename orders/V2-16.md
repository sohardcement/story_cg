# 工单 V2-16：每镜加"多余身体局部"检查，检出时先重抽 seed

依据 V2-15 的离线评估（`reports/V2-15.md`）和监工决定 D59：

- 现有人数门禁对"没有脸的多余身体局部"召回 0/6；
- 用视觉模型问一个定向问题，召回 5/6，误报 1/73（那 1 张监工复看后改标为"不确定"）。

工作目录、写入范围、git 规则同 V2-10（AGENTS.md 第 8、9、10 条）。

## 要做

1. **新增检查项 `extra_body_part`**：
   - 问题沿用 V2-15 的 M3 提示词和 schema（`extra_part`、`location`、`description`）。
   - 提示词和 schema 放进配置，并注明来源是 V2-15。
   - 提示词不得写死"a single woman"：主角的说法从该任务的 identity 生成（例如 1girl 或 1boy 对应的说法），取不到时用中性说法"one main character"。
2. **在哪里做**：
   - 每镜的首轮审核和每个修复候选的审核（`audit_candidate`）里，人数门禁之后做一次，每次审核 1 次视觉调用。
   - 人数门禁已经判为重复时，不再问。
   - 交付前的整体审核也带上这一项。
3. **算什么级别**：
   - 阳性时记为 fail，级别和人数门禁相同，都是 D29 的第 0 级，计入可靠项。
   - 依据是 V2-15 的标定。审核记录里写明 calibration 来源，以及样本量小（正例 6 张）。
4. **怎么修**：
   - 检出后的修复方法和人数门禁一样，先重抽 seed，只重抽 1 次。新图用同一个问题复核。
   - 采用新图要同时满足两条：复核为阴性；改善判定通过（含 V2-14 的分级退化否决）。
   - 仍为阳性时，保留评分更好的那张，并在交付说明的已知问题里写一句"第 N 镜疑似有多余身体局部（位置、描述），待人工复看"。
   - 不新增 instruction_edit 或局部重绘之类的修法，留到以后有证据再说。
5. **预算**：每组新增的视觉调用约等于审核次数。报告里要写清楚，现有每组调用上限（`max_vision_calls` 等）在最坏情况下够不够用。不够时，只在报告里给出建议值，不要自己改上限。

  - 首轮审核阳性时触发重抽 seed；

  - 仍为阳性时，保留原图并写进交付说明；
  - 人数门禁判为重复时，不问这一项；
  - 提示词按 identity 生成主角说法。
