## 第一步：审核器 v3

1. **阈值以下额外人物**（D21）：本机检测中未计入主体的较小人物/人脸，裁切（适当外扩）后送视觉模型做发色、发型（以及可见时的瞳色）审核，与身份卡（identity 锁定 tag + 定妆面部）比对，输出 `extra_protagonist: ok / duplicate / not_visible` 与证据。分镜声明 reflection 的倒影按允许处理；路人、局部的手不算主角。结果并入单主角计数项（或作为新项）参与可靠性体系。
2. **服装细节对定妆图**：新增审核项，让视觉模型并排看定妆全图与当前图，逐项比较袖长、领口、上衣/裙/裤的长度、外层衣物有无、主要颜色块；服装状态在分镜中声明换装的镜头，比对该套服装的首次出现镜头或其定妆（若有）。按"看得见才判"的规则给出 `ok / mismatch / not_visible`。
3. **配饰放大审核**（D22）：对头部（含耳朵、发饰位置）按检测框放大裁切后单独审核发饰/配饰；与定妆头部裁切并排比对。
4. 离线测试后**冻结 v3**：`calibration/v3/reviewer_freeze.json`（审核器、提示词、检测阈值、执行脚本哈希）。冻结后本工单内不再改。
