## 二、分镜规则（TASK-v2 §2.2 第 1、2、4、5、6、7 条）

1. **命中规则**：一镜的景别、视角、动作 tag 和表中某条一致，就算命中，场景和表情不同不影响。表情不同时在记录里注明。动作 tag 一致、但景别或视角不同的，算表外。
2. **分档查询**：角色层级是 L1 或 L2 时，直接查该层级的分档。L3、L4 或没有数据的，取 L1 和 L2 两档里较保守的一档（稳定 > 有时 > 不可用，取后者）。
3. **表外动作**按"有时"处理（D32）。"有时"（含表外）每组最多 1 镜。"不可用"直接拒绝，并给出替代。
4. **分镜模型的提示**里要提供：本角色层级下的稳定项清单、有时项清单、不可用项及替代。这样模型一开始就优先选稳定项，而不是靠事后拒绝来回试。
5. 校验失败时，重试请求里要带具体的违规条目，例如"第 3 镜：动作 running 在 L1 为不可用，替代为 18"。
6. **表外动作的结果写回**：任务结束后，把每个表外镜头的动作 key、层级、运行时审核结论和证据图片路径，追加到一个观察记录文件。
   - 这些记录标"未经人工判定"，**不自动改分档**；
   - 分档只能由用户判定后修改。
   - 文件位置写进配置。
