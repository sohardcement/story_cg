# 工单 P5-01：修复手段（原语）——区域重绘、面部精修、单镜重布局

你是执行者，先读 AGENTS.md（含「监工补充禁令」），再读 TASK.md §6，以及 `reports/P3-02.md`、`reports/P4-02.md` 和 `orders/P3-02.md` 末尾的监工结论。在现有代码上继续。

## 目标

实现 TASK.md §6 列出的几类修复手段，作为可被修复循环（P5-02）调用的原语，并逐个在**真实的失败镜头**上验证效果。本工单不做自动循环编排。

## 要实现的修复原语

每个原语都必须：走正式的状态落盘/恢复机制（先写状态、prefix 含 job/shot/attempt、按 prefix 对账）；产出新 attempt，不覆盖原图；在 state/manifest 中记录"诊断 → 假设 → 改动 → 结果"四段（结果由修复后的真实审核与看图填写）。

1. **区域重绘（inpaint）**：输入一个区域（来自视觉模型给出的 bbox，或脚本从已有裁切推导），生成羽化 mask，用 WAI + 画风 LoRA + IPAdapter（定妆脸）对该区域局部重绘；提示词由脚本从状态拼装（身份块 + 服装块 + 该区域相关的 shot/prop tag）。用于：道具错误、多余物体、服装局部漂移、手部。
2. **面部精修（face detail）**：全身/远景里脸只有约 100px，瞳色和五官不稳（P2、P3 都观察到）。做法：按面部 bbox 外扩裁出头部区域 → 放大到 SDXL 合适尺寸 → WAI img2img（IPAdapter 定妆脸，较低 denoise）→ 缩回并羽化贴回原图。用于：身份漂移（瞳色、发型细节、耳饰）。
3. **单镜重布局**：对某一镜启用 Qwen 布局模式（P3-02 已实现）重新出这一镜，可同时让运行时 LLM 按诊断改写该镜的构图字段（景别、机位、道具位置）并通过原有 schema 校验。用于：动作不成立、道具/空间关系错误、画面关系不清。
4. **换 seed**：允许作为手段之一，但调用时必须附诊断记录；无诊断的换 seed 调用直接报错（写离线测试）。

## 验证（在真实失败镜头上各试一次）

从已有任务中选下列失败镜头（都在 P3-02 的正式任务目录里），每个原语至少试 1 例：

| 原语 | 目标镜头 | 已知问题 |
|---|---|---|

| 区域重绘 | `runs/p3_02_a_ipadapter/` 第 4 镜 | 两把伞都在手里，没有按分镜放下一把 |
| 面部精修 | `runs/p3_02_a_ipadapter/` 第 1 镜 | 远景脸小，瞳色偏黄/金，非原设绿色 |
| 面部精修 | `runs/p3_02_a_none/` 第 3 镜 | 蓝瞳（原设绿瞳）——无参考条件下的身份漂移 |

修复写入**新的修复任务目录**（例如复制源任务状态到 `runs/p5_01_<源任务>/` 后在其中产生新 attempt），不改动 P3-02 的原任务目录。
