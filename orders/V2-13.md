# 工单 V2-13：修图诊断的异常输出不再让任务崩溃；修图不得加道具；写分镜说明里的近景道具规则改正

对比集第 4 轮暴露出两个问题。工作目录、写入范围、git 规则同 V2-10（AGENTS.md 第 8、9、10 条）。

## 问题与证据

1. **修图诊断的输出格式错了，任务直接崩溃**。第 1 组 r2（`.v2/jobs/cg-44fa1c8a334e`，只读）停在 `KeyError: 'relation_tags'`。
   - 第 2 镜诊断选了 relayout，本地模型返回的 `shot.key_props` 是 `[{"name": "kitten", "description": "..."}]`，不符合 production schema 里 key_props 条目的格式（必须有 `prop_id`、`relation_tags` 等）。
   - 第 1 次输出因"每镜最多一个道具"被拒（ValueError），按规则重试一次；重试的输出 `prop_tags` 清空了，`key_props` 仍是错格式。
   - 校验走到 `validate_storyboard` → `posture_tags.tag_fields` 取 `r['relation_tags']` 时抛 KeyError。`run_cycle` 只把 ValueError 和 jsonschema.ValidationError 当成"诊断被拒"，KeyError 一路抛出，整个任务停止，已出的 4 张图也没有交付。
   - 证据：`cycle_artifacts/decision_2_1_contract6.json`、`decision_2_1_contract6_rejected.json`、`decision_2_1_contract6_validation1.json`。
2. **修图在给镜头加道具**。同一份输出里，模型给本来没有道具的第 2 镜加了一只 kitten。TASK-v2 §0 规定道具只删不加；分镜阶段由 agent 声明道具，修图不能新加。
3. **`beats-guide` 里的近景规则和 V2-11 矛盾**。说明里写着 "closeup keeps only setting/place/time tags and NO objects"，但 V2-11 已经让近景保留本镜声明的那一个道具（`prop_tags`）。第 1 组两份 beats 的近景镜头都没写小猫；第二份 beats 干脆只在 `spatial_relation` 里写了 kitten，4 镜 `prop_tags` 全空，画面上没有猫（第 3 镜抱的是一只玩偶熊）。说明里虽然有 "Only tags arrays enter the image prompt"，但 "Props are background only" 和近景 "NO objects" 让写分镜的 agent 不敢把剧情里的动物或物件写进 `prop_tags`。

## 要做

1. **诊断输出先做 schema 校验**：
   - 诊断结果里的 `shot` 不为 null 时，在任何语义校验之前，用 `runtime_gate.diagnosis_schema` 里那份 production shot schema 做 jsonschema 校验。
   - 不通过就按"诊断被拒"处理：走现有的重试；重试用完后记 `diagnosis_rejected`，继续处理其他镜头，不让任务停止。
   - 被拒的原因写进现有的 `_rejected.json` 记录。
2. **修图不得加道具**：relayout 返回的 shot 里：
   - `key_props` 必须和当前镜头的一样；
   - `prop_tags` 必须是当前镜头 `prop_tags` 的子集，可以删，不能加。
   - 违反时按"诊断被拒"处理，原因写明"修图不得新增道具"。
   - 诊断提示词里加一句对应的英文规则。
3. **`beats-guide` 说明改正**（规则文本由 `plan_story` 和 `beats-guide` 共用，改一处即可）：
   - 近景这一条改成：近景只保留地点、时间、天气和光线类 tag，加上本镜声明的那一个 `prop_tags`；其他物件一律不保留。中景、远景的说法不变。
   - 把 "Props are background only" 改成不会让人误解的说法。意思是：道具只是普通 tag，不登记、不绑定持有者；但剧情需要在这一镜画出来的那个物件或动物（被拿着的、被发现的、被看着的），必须写进本镜的 `prop_tags`。只写在 `spatial_relation`、`description` 等文字字段里，画面上不会出现。
   - 措辞保持通用，不得出现测试剧情里的具体物件（AGENTS.md 第 2 条）。
