## 要做

### A. 新模块 `src/storycg/prune.py` 和 `storycg prune` 命令

命令：`storycg prune [--days N] [--apply]`。`--days` 默认 7。不带 `--apply` 只列出、不删任何东西。

清理两类，都只在项目根下的 `compile/` 和 `jobs/` 里：

1. `compile/cmp-*` 目录：目录里最新文件的 mtime 早于 N 天，整个目录删掉。
2. `jobs/cg-*` 任务目录，同时满足下面三条的，删掉 `cycle_artifacts/` 下的 `*.png`（只这一层）和 `review_artifacts/` 下任意层的 `*.png`；其余文件一律不动（json、候选原图、定妆图、`delivery/`、`face_refine/` 都留着）：
   - `agent.json` 的 `phase` 是 `completed`、`stopped`、`needs_user` 或 `cancelled`；
   - `agent.json` 的 mtime 早于 N 天；
   - worker 不在运行（用 `storycg.agent.worker_alive(root)` 判断）。
   `awaiting_approval` 和其他运行中的阶段一律跳过。

规则：

- 不跟随符号链接：遇到符号链接（文件或目录）跳过，不删、不进入。
- 删除前确认路径解析后仍在项目根的 `compile/` 或 `jobs/` 下，否则跳过。
- 输出一个 JSON 对象到 stdout：`{"applied": bool, "days": N, "compile_dirs": [...], "job_files": {"<job_dir>": {"files": n, "bytes": n}}, "skipped": [{"path": ..., "reason": ...}], "total_bytes": n}`。`compile_dirs` 每项带路径和字节数。
- 在 `src/storycg/agent.py` 的 `main()` 里加 `prune` 分支：和 `beats-guide`、`compile` 一样，在 argparse 主解析器之前分派（`if argv and argv[0] == 'prune': return prune_cli(argv[1:])`），help 里加一行。**agent.py 只加这几行，别的不动**（监工同时在 `.v2` 里改 agent.py，合并时要少冲突）。
