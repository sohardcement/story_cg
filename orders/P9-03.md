# 工单 P9-03：第二轮校准样本（只做样本，不跑审核）

先读 AGENTS.md（含补充禁令 4、5）、监工的样本设计 `verify/P9-calibration-v2-design.md`（只读）、PROGRESS.md 决策 D11、D14、D15。

## 目标

按设计文件准备 A（看不见 vs 不存在）、B（单主角计数）、C（瞳色采样）三组样本，做成带编号的总览图交给监工逐张确认真值。**本工单不调用审核器、不跑检测类审核项统计**；统计在 P9-04（审核器改版 + 冻结 + 校准）里做，且只用监工确认过的样本。

## 要做的事

1. 按设计文件逐个编号准备样本，保存到 `calibration/v2/samples/<编号>.png`，每个配 `<编号>.json`：来源图路径与 sha256、做法、对应的分镜要求（含 `reflection`、`other_people` 等字段）、身份/服装清单、"声称的真值"（只是你的预期，监工会核对）。
   - A1、A2、A5、A6、A7：从已有图片里按设计要求挑（例如 A1 要"约尔正面、发髻在脑后看不到"），说明为什么选这张；挑不到合适的就写明缺口，不要硬凑。
   - A3、A4：直接复制 `calibration/samples/E4b.png`、`E4a.png`。
   - B1、B4–B10：按设计文件的来源复制或挑选。
   - B2、B3：用 Qwen Image Edit（已有 workflow）在两张单人正确样本里"在画面中再加一个同一人物"（同角色、同服装、不同姿势），各编辑 1 次；没生效就如实标注，最多带诊断重做 1 次。
   - C 组：按设计文件的来源复制。
2. 做总览图 `review/P9-03-samples.jpg`：每格标编号和声称的真值（一句话），A/B/C 分区，附相关角色的定妆图作参考。
3. `reports/P9-03.md`：每个样本的来源、做法、是否生效、你自己看图的判断。

## 必须产出

- `calibration/v2/samples/*.png` 与 `*.json`、`review/P9-03-samples.jpg`、`reports/P9-03.md`

## 不许做

- 不调用审核器或视觉模型做判断；不计算检出率。
- 不自行增删编号或改变编号含义；不改 `verify/` 下任何文件。
- 不针对角色写特例；不接入 Qwen-Image 2.1；不在 Windows/MacBook 上做任何事。
- 不 git commit；不写 `~/.hermes`；不改 TASK.md / SUPERVISOR.md / PROGRESS.md / orders/ / AGENTS.md。

## 预算

- 出图上限 4 张（B2、B3 各 1 次 + 各 1 次带诊断重做）；视觉调用 0；时长 45 分钟。
