# 工单 P4-01：制作审核器校准样本（只做样本，不跑审核）

你是执行者，先读 AGENTS.md（含「监工补充禁令」），再读 TASK.md §3 的 P4、§7，以及监工的样本设计 `verify/P4-sample-design.md`（只读，不要改）。

## 目标

按监工设计的清单制作校准样本，做成一张带编号的样本总览图交给监工逐张确认。**本工单不调用审核器**；审核器统计在 P4-02 做，且只统计监工确认过的样本。

## 样本来源

- 角色 A：芙莉莲；角色 B：约尔。定妆图、identity、默认服装用 P3-02 已审核通过的那一份（缓存里有）。
- 基础正确图：从 P3-02 中"有参考"条件（IPAdapter 0.4）的成图里取，每个角色 3 张作为"正确样本"候选。不要挑选，按镜号 1–3 取；若某张明显有错，照实标注，由监工决定是否剔除。
- 单变量编辑：优先用 Qwen Image Edit（P3-01 已有 workflow）对**正确样本**做只改一个属性的编辑。为了排除"经过 Qwen 处理本身让画风变了"的干扰，另对每个角色的 1 张正确样本做一次"保持不变"的 Qwen 空编辑，作为**处理对照样本**（它应当被判为正确）。

## 样本清单（编号固定，与设计文件一致）

| 编号 | 做法 |
|---|---|
| E1a | 用 A 的某一镜分镜 + B 的身份块/定妆参考生成（换了角色） |
| E1b | 用 A 的同一镜分镜，去掉角色 tag 与作品 tag，只保留通用外观 tag 生成（相似的陌生人） |
| E2a / E2b | 对 A、B 各一张正确样本，只改发色（改成与原设明显不同的颜色） |
| E3a / E3b | 对 A、B 各一张正确样本，只改瞳色 |
| E4a / E4b | 对 A、B 各一张正确样本，只去掉一件发饰或配饰（从 identity/outfit 里选一件画面中确实可见的） |
| E5a | A：整套服装换成完全不同的服装 |
| E5b | B：只改一件服装部件的颜色（部件级变化） |
| E6a / E6b | 分镜要求手持某道具，图中拿的是别的东西（E6a）或同类道具但颜色不对（E6b）。可以用编辑，也可以按改过的分镜重新生成；样本记录里要写清"分镜要求什么、图里实际是什么" |
| E7a / E7b | 分镜要求某动作（例如奔跑、坐下），图中是明显不同的动作（例如站立）。做法同上 |
| C1–C6 | 正确样本：A、B 各 3 张 |
| Q1–Q2 | 处理对照样本：A、B 各 1 张 Qwen 空编辑 |

## 要做的事

1. 按清单生成/编辑样本，保存在 `calibration/samples/<编号>.png`，每个样本配一个 `calibration/samples/<编号>.json`：角色、来源图、做法（完整 workflow 或编辑指令）、该样本对应的"分镜要求"（shot 描述、道具、动作，给审核器用）、预期被判错的审核项。
2. 做样本总览图 `review/P4-samples.jpg`：每格标编号和一句"声称的错误"，附上该角色定妆图作参考列。如果某个编辑实际没有生效（例如瞳色没变），**不要**换 seed 反复重抽，照实在 json 里写 `edit_effective: false` 并在报告里列出——最多允许对同一编号带诊断地重做 1 次。
3. `reports/P4-01.md`：列出每个样本的做法、是否生效（你自己看图的判断）、用量。

## 必须产出

- `calibration/samples/*.png` 与 `*.json`（共 22 个编号）
- `review/P4-samples.jpg`
- `reports/P4-01.md`

## 不许做

- 不调用审核器，不计算检出率。
- 不自行增删编号或改变编号含义；不改 `verify/P4-sample-design.md`。
- 不针对角色写特例；不装节点、不下载模型。
- 不 git commit，不写 `verify/`，不改 TASK.md / SUPERVISOR.md / PROGRESS.md / orders/ / AGENTS.md。

## 预算

- 出图上限 30 张（22 个样本 + 最多 6 次带诊断重做）；视觉调用 0；时长 60 分钟。
