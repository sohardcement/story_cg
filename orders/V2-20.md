# 工单 V2-20：暂不使用任何 LoRA（D62）；层级缓存的键加上画风 LoRA

先读 `TASK-v2.md` §10（尤其 §10.4），以及 `AGENTS.md`（尤其第 8、9、10 条）。

工作目录是 v2 工作树 `/work/workspace/manga_skill/.v2`（分支 `v2`）。所有读写都只在这个目录内。

## 背景（监工已查，行号供参考）

- **画风 LoRA**：
  - `config/default.json` 的 `style_loras` 里有两个：Iwao178 0.4、akaimelon 0.3。
  - `config.py` 要求正好两个。
  - `workflow.py` 固定用节点 2、3 加载这两个 LoRA，下游的 model 和 clip 都接 `["3", 0]` / `["3", 1]`。
  - `tiers.add_character_lora` 也按节点 3 改接线。
  - `fallback._injected_workflow` 断言 LoraLoader 正好 2 个。
  - `agent.check_resources` 按 `style_loras` 检查资源。
- **角色 LoRA**：`tier_gate.ensure_identity_tier` 调 `tiers.match_character_loras` 自动匹配，匹配上就判 L1，再由 `add_character_lora` 插入节点 30。
- **层级缓存键**：`tier_cache.model_fingerprint` 只含角色、底模和角色 LoRA，不含画风 LoRA。
- **词汇表**：层级未定、L3、L4 时，取 L1、L2 两列里较保守的一档（`config/shot_vocab.json` 的 `unknown_tier_rule`）。L1 一列是月城柳带专用 LoRA 测出来的。

## 要做

1. **默认配置不加载任何 LoRA**：
   - 画风 LoRA：`style_loras` 允许 0 个或任意多个，默认配置改为空列表。
   - 角色 LoRA：加一个配置项，名字由你定，默认关闭。关闭时不做 LoRA 匹配，层级只可能是 L2、L3 或 L4。L1 和 LoRA 匹配的代码保留，以后重新打开只改配置、不改代码。
2. **workflow**：LoRA 为 0 个时，不生成任何 `LoraLoader` 节点，下游的 model、clip 直接接底模节点。
   - 把所有构建或改写 workflow 的地方查一遍：正式出图、定妆图、层级探针、L3 的 IPAdapter 注入、`add_character_lora`、修图的各种 workflow。
   - 按 LoRA 节点数断言的地方也一起改。
3. **层级缓存键**：加上画风 LoRA 的组合，每个都带上名字、大小和强度。空列表也要进键。
   - 已有缓存条目不删也不改。新键不会命中旧条目，下次运行时会重新判定。
   - 定妆图的缓存键（`reference.cache_key`）会不会随画风 LoRA 变化，查清楚，写进报告。
4. **词汇表取档**：角色 LoRA 关闭时，L1 一列不参与取档。层级未定、L3、L4 一律按 L2 一列取档。
   - 角色 LoRA 打开时，行为不变。
   - `beats-guide` 和 `compile` 的输出里，写明按哪一列取档。
5. **资源检查**：`check_resources` 按实际配置检查，LoRA 为 0 个时不查 `LoraLoader`。Qwen 相关的资源检查不在本单范围内，不改。

## 验证

- **测试**：
  - **无 LoRA 节点**：默认配置下，正式出图、定妆图、层级探针、L3 注入这几种 workflow 都没有 `LoraLoader` 或 `LoraLoaderModelOnly` 节点。Qwen 编辑 workflow 不算在内（它属于修图，下一单移出默认流程），在报告里单独列出。
  - **图完整性**：每个节点的输入引用 `[id, n]` 都要指向存在的节点。分别在下面几种配置下检查：0 个画风 LoRA、2 个画风 LoRA、角色 LoRA 打开、角色 LoRA 关闭。
  - **回归**：配成 2 个画风 LoRA、角色 LoRA 打开时，生成的 workflow 和改动前一致。用改动前的代码先生成快照，再和改动后比对。
  - **缓存键**：画风 LoRA 不同，键就不同；默认配置下，`cache/identity_tiers.json` 里现有的两条都不命中。
  - **层级判定**：用假服务写集成测试，走真实的 `ensure_identity_tier`。角色 LoRA 关闭时，即使 LoRA 清单里有能匹配的 LoRA，也不会判 L1。
  - **词汇表**：角色 LoRA 关闭、层级未定时，L1 不可用、L2 稳定的条目（第 2、3 项）按稳定处理。
- **全量测试**通过。`--basetemp` 要放在工作树内。
- **离线核对**：对 `菲伦`、`喜多川海梦`、`芙莉莲` 各运行一次 `storycg beats-guide --character <名字>`。这条命令只读，会访问 Danbooru，但不出图、不调用模型。报告里贴出每个角色解析到的 tag 和取档说明。
