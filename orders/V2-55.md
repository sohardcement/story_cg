## 背景（监工已复现）

1. **道具 tag 被 Danbooru 校验删掉，报的是不带镜号的全局错误。**
   - 复现：`verify/v2/remeasure-d91/beats/h1.a5.json`（主线工作区，只读）第 1 镜 `shot.prop_tags` 是 `["pot"]`。编译结果 invalid，错误只有一条：`{'shot': None, 'field': '-', 'problem': 'ValueError: prop tag must remain in scene.tags after tag validation', ...}`。
   - 原因：`beats.compile` 里 `validate_tag_lists(..., drop_unknown=True)`（`beats.py` 约 638 行）把 `pot` 从 `1.scene.tags` 删了（plan_log 的记录是 `{"input": "pot", "exists": false, "field": "1.scene.tags", "action": "discarded"}`），但 `shot.prop_tags` 里还留着它；之后 `planning.validate_storyboard` 的检查（`planning.py` 约 284 行）抛 `ValueError`，被 `beats.py` 约 654 行包成全局错误。
2. **身体部位的写法不被认可时，报错说成了"只能写一个动作子句"。**
   - 复现：`h1.a4.json` 第 2 镜 `shot.spatial_relation` 是 `"spoon touching lips"`，报错 `这个字段只能写一个动作子句："spoon touching lips"`。可它本来就只有一个动作。
   - 原因：`appearance_forbidden(value, body_action=True)` 只放行整句正好是 `[subject|person|character|hands|fingers|palms] <ACTION_VERBS 里的动词> [the|own|their|her|his] <face|eyes|mouth|ears|lips|nose>`，或 `hands on/over/against <部位>` 的值（`planning.py` 的 `BODY_ACTION`、`plain_action`）；前后多一个词就不放行（`spoon touching lips`、`covering mouth with hand`、`turns back to face front` 都会被拦）。`body_target_violation` 在没有外貌词时一律返回 `'clause'`，`beats.py` 约 419 行据此说"只能写一个动作子句"。

## 要做

1. **道具 tag 被删时报到镜号。** 编译时，`validate_tag_lists` 删掉或替换的 tag 如果也在那一镜的 `shot.prop_tags` 里，就报一条 BeatsError 错误：`shot` 是镜号，`field` 是 `shot.prop_tags`，`problem` 写明哪个 tag、原因（Danbooru 上不存在或已废弃；替换的写出替换成了什么），`fix` 写"换一个 Danbooru 上存在的 tag，或从 prop_tags 去掉"。同一次编译里其他错误照常一起列出。`planning.validate_storyboard` 里原来的检查保留，当最后一道保险。
   - "替换"（别名换成正式 tag）这种情况现在是 valid 还是 invalid，先在旧代码上查清楚，写进报告。**原来 valid 的必须仍然 valid**；原来 invalid 的，只是报错变准。
2. **身体部位报错写准。** `body_target_violation` 返回 `'clause'` 时，报错不再说"只能写一个动作子句"，改成说清楚规则：
   - `problem`：这个字段里有身体部位词（写出是哪个词），但整句不是认可的写法；
   - `fix`：列出认可的两种写法，动词列表**从 `ACTION_VERBS` 生成**，不在报错文字里手写；说明前后不能有别的词，举一个改法（比如 `touching lips`），并说也可以去掉身体部位词（比如 `tasting soup`）。
   - `'appearance'` 那一支的报错不改。`appearance_forbidden`、`body_target_violation` 的判定结果不改，beats-guide 的写作说明不改。
