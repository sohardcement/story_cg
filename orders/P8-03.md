# 工单 P8-03：修复"同类道具区分 × tag 存在性过滤"冲突，补跑 L3 角色整组剧情

先读 AGENTS.md（含「监工补充禁令」）、`reports/P8-02.md` 与 `orders/P8-02.md` 末尾监工结论。在现有代码上修改。

## 问题（P8-02 实测）

白雪姬面包店剧情的分镜 5 次被拒：运行时 LLM 用颜色区分同类道具（几种面包），但颜色复合 tag（如"某色+面包"）在 Danbooru 不存在，被 tag 存在性过滤丢掉；过滤后同类道具描述相同，于是"同类道具必须可区分"规则拒绝整版分镜。两条规则叠加，让合理的分镜无法通过。

## 要做的事（通用规则，不写"面包"等词）

1. 区分规则只针对**剧情需要区分**的同类道具：同一镜里同时出现、且持有者/归属/状态不同的同类道具（例如拿错的两把伞）才必须可区分；只是作为场景陈设的同类物品（货架上的一排商品）不登记为独立关键道具，或合并成一个"群组"道具，不触发区分规则。在 schema/提示词里说明，校验器实现。
2. 当颜色复合 tag 不存在时，允许用"颜色 tag + 物体 tag"两个真实 tag 组合表达区分（例如分别校验颜色 tag 与物体 tag 存在），区分比较用组合后的描述。补离线测试：复合 tag 不存在但拆分后存在 → 通过；陈设群组不触发区分；真正需要区分的同类道具仍然必须可区分。
3. 用正式默认入口补跑：`--tag shirayuki_hime_(precure)`，剧情 `白雪姬第一次在面包店打工，把面包摆满货架后满意地叉腰笑了。`（复用已验证的 L3 定妆缓存）。完成后拼图复制为 `review/白雪姬-面包店打工.jpg`，更新 `reports/P8-01.md` 矩阵表，写 `reports/P8-03.md`（逐镜看图判断、盲审、用量、已知问题）。
