# 工单 P1-01：项目骨架 + ComfyUI 客户端 + 单镜出图

你是执行者，先读 AGENTS.md，再读 TASK.md 的 §1、§2、§5、§6（前两条）。本工单是 P1 最小闭环的第一步：搭好骨架，能按"先落盘状态、再提交、可恢复"的方式出 1 张真实图片。

## 已核实的环境事实（监工 P0 核对，见 PROGRESS.md）

- ComfyUI：`http://127.0.0.1:8188`，Windows，RTX 4070 SUPER 12GB，无认证。`/object_info` 冷启动可能要 40 秒以上，客户端超时至少 180 秒。**ComfyUI 是共用的**：队列里可能有别人的任务，绝不能清空队列、不能 interrupt、不能删除 history；只按自己的 prompt_id 追踪。
- 底模：`waiIllustriousSDXL_v170.safetensors`（CheckpointLoaderSimple）。画风 LoRA 暂用 `Iwao178.safetensors`、`akaimelon.safetensors`（P2 再定参，本工单给一个临时配置即可，例如各 0.5）。akaimelon 训练集以 NSFW 为主，负面提示词要压住（全年龄输出）。
- 模型服务（LLM 与视觉同一个）：`http://127.0.0.1:11234/v1`，OpenAI 兼容，模型 id `Qwen3.8-Flash-Next-Uncensored-MLX-Serve-4bit`，无需 key，支持多图与 json_schema。本工单不必用到。
- 本机系统 python 3.14 没有 Pillow。用 `uv` 在工作目录建 `.venv`；沙盒里 uv 默认缓存目录不可写，请设 `UV_CACHE_DIR=$PWD/.uv-cache`。

## 要做的事

1. Python 项目骨架（包名自定，建议 `storycg/`），`pyproject.toml` 由 uv 管理，依赖尽量少（Pillow、requests 或 httpx、jsonschema、pytest 之类）。
2. `.gitignore`：忽略 `.venv/`、`.uv-cache/`、`__pycache__/`、`runs/**/*.png`（完整单图不进 git，由 manifest 记录路径和 sha256）；**不要**忽略 `review/`、`reports/`、`runs/**/*.json`。
3. 配置：`config/` 下放 ComfyUI 地址、模型服务地址、超时、按景别选择的分辨率表（至少 wide / full / medium / closeup 四档，SDXL 合法尺寸）、预算默认值（TASK.md §6）。代码里不写死这些值。
4. ComfyUI 客户端模块：上传图片、提交 prompt（带 client_id）、轮询 `/history/<prompt_id>`、查询 `/queue`、下载输出图。
5. 任务状态：每个任务一个目录 `runs/<job_id>/`，`state.json` 原子写入（写临时文件再 rename）。每张图的每次尝试记录 job、shot、attempt、seed、完整 workflow、prompt_id、状态。
   - **提交前**先把"即将提交"的记录写盘，`filename_prefix` 必须包含 job、shot、attempt 的 ID。
   - 恢复时先查 `/queue` 和 `/history` 核对：已在队列就继续等，已完成就下载，确认未提交或已失败才重新提交。不得重复提交。
6. WAI 文生图 workflow 构建函数（checkpoint + 两个画风 LoRA + 正负提示词 + 分辨率 + 采样参数），参数全部来自配置。
7. CLI（入口自定，例如 `python -m storycg`），本工单至少提供：
   - `gen-one`：给定 job 目录、shot id、正向 tag 文本、景别，出 1 张图，按上面的状态规则执行。
   - `status <job目录>`：打印状态。
   - `resume <job目录>`：按第 5 条对账恢复。
8. 离线测试（pytest）：状态原子写、恢复对账逻辑（用假的 queue/history 数据测判断分支）、filename_prefix 格式、workflow 结构。离线测试只证明逻辑，不能当作出图证据。
9. 真实运行：用 `gen-one` 出 1 张图，提示词用一个底模很可能认识的角色 tag，例如 `1girl, frieren, sousou no frieren, standing in a flower field, upper body`（这只是冒烟用的临时文本，不要写进代码）。再做一次恢复测试：提交后立即杀掉进程，再运行 `resume`，证明没有重复提交（在报告里给出 `/history` 里同 prefix 只有一条记录的证据）。
