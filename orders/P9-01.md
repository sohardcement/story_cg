## 背景

用户决定（D10）：在 **omarchy 本机**工作目录的虚拟环境里安装 ultralytics，加载 Bingsu/adetailer 的面部和人物检测模型；不碰 Windows（ComfyUI）与 MacBook（视觉模型）。之后的局部重绘蒙版（D10）、瞳色/配饰颜色采样（D11）、单主角计数（D15）都建立在这个检测上。本工单只做检测基础设施和检测效果校准，不接入生成与审核流程（P9-02 再做）。

## 要做的事

1. **安装**：在 `.venv` 里加入 ultralytics（`UV_CACHE_DIR=$PWD/.uv-cache`）。omarchy 只做 CPU 推理即可，torch 用 CPU 版本以免下载 CUDA 大包（例如 PyTorch 的 CPU wheel 索引）；写清楚实际安装的版本。默认 `uv run pytest -q` 必须继续全过。
2. **模型**：从 `https://huggingface.co/Bingsu/adetailer` 下载 `face_yolov8s.pt`（或 n/m，说明选择理由）和 `person_yolov8s-seg.pt` 到 `models/detect/`，记录来源 URL、文件大小、sha256 到 `models/detect/manifest.json`。权重文件不进 git（加入 .gitignore），manifest 进 git。
3. **检测模块**（例如 `src/storycg/detect.py`）：
   - `detect_faces(image)` → 面部框（像素坐标 + 置信度）；`detect_persons(image)` → 人物框 + 分割蒙版（如模型提供）+ 置信度 + 占画面面积比。
   - 蒙版工具：把框或分割结果转成羽化蒙版（尺寸与原图一致），可按比例外扩。
   - 面部裁切工具：按检测框外扩裁切（取代当前用视觉模型给 bbox 的做法，P9-02 接入）。
   - 阈值（置信度、最小面积比等）写配置文件，不写死。
   - CLI：`python -m storycg detect <图片…> [--overlay out.jpg]`，输出 JSON 并可画叠加图。
