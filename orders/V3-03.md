# 工单 V3-03：选图前不预写"已选"；reshoot 后默认指向新一轮（TASK-v3 §3.1 第 6 条）

起因：2026-10-19 用户视角跑 /story-cg（`jobs/cg-ed4224ca2074`）。每镜停在 awaiting_pick 时 `candidates.json` 已写 `selected: 1` 和一条"3 张通过筛选的候选中，按第 2 级（candidate number）分出胜负"的理由，`pending_sheet.jpg` 上 cand1 标 SELECTED，`status` 的 `progress.shots[].picked` 为 true、`completed_shots` 把没选的镜也算进去。reshoot 第 4 镜后新旧两种机位的 6 张混在一张拼图里，`default_candidate` 仍是旧机位的候选 1，槽位顶层的 `user_pick` / `picked_by` 还是 reshoot 前的值。

工作目录、守则、命令同 V3-01（`.v3`，`PYTHONPATH=$PWD/src`，basetemp `.pytest-tmp/V3-03`）。在 V3-02 验收后做，开工先跑全量记基线。

## 现状（代码位置，都在 `src/storycg/`）

- `candidates.py` `run_candidate_delivery()` 尾部：`chosen, reason = pick(slot['candidates'])` 之后直接 `slot['selected'] = …`、`slot['reason'] = reason` 落盘，然后 `human_review(config)` 时 `write_pending_sheet` 并 `raise ReviewPause`。
- `candidates.py` `write_pending_sheet()`（约 192 行）、`write_candidate_sheet()`（约 841 行）：`r['candidate'] == slot['selected']` 标 SELECTED，其余 kept / SCREENED。一个镜一行，不分轮次。
- `agent.py` `_pending_pick()`：`default_candidate = slot.get('selected')`。
- `agent.py` `_progress()`：`picked = slot.get('selected') is not None`；`completed_shots` 按它数。
- `candidates.py` `pick_pending()`：`auto = slot.get('selected')`，写 `auto_selected` / `auto_reason`，理由"由{用户|调用方看图}选择候选K（默认候选N）"。
- `candidates.py` `reshoot()`：只 `pop('confirmed')`、`more += 1`；`selected` / `user_pick` / `picked_by` / `auto_*` 留着；重出停下时 `pick()` 又把 `selected` 写成排序第一（一般还是候选 1）。

## 要做

只改人选模式（`human_review(config)` 为真）的路径；审核器模式（review_mode 不是 human）的行为一字不动。

1. 停下等选时：`slot['selected'] = None`、`slot['reason'] = None`；排序结果写 `slot['auto_selected']` / `slot['auto_reason']`；新键 `slot['default_candidate']` = **最新一轮**候选里 `pick()` 排序第一的那张（第一轮时就是 auto_selected；该轮没有通过筛选的，取该轮第 1 张）。
2. `_pending_pick().default_candidate` 读 `slot['default_candidate']`。
3. `_progress()`：人选模式 `picked = bool(slot.get('confirmed'))`，`completed_shots` 跟着变（没选的镜不算）；审核器模式照旧。
4. 拼图标签：没 confirmed 的镜，`default_candidate` 那张标 `default`，其余 `kept` / `SCREENED …`；confirmed 后 `selected` 那张标 `SELECTED`。`pending_sheet` 和 `candidate_sheet` 都按轮次分行：一个镜有多轮时每轮一行，行首标签 `shotNN round R`（ASCII）。
5. `pick_pending()`：`auto` 取 `slot['default_candidate']`，不再从 `selected` 推；第 1 步已写的 `auto_selected` / `auto_reason` 不要覆盖成 None。理由文案不变。
6. `reshoot()`：把 `selected`、`reason`、`confirmed`、`user_pick`、`picked_by` 从槽位顶层清掉，旧值存到 `slot['before_reshoot'] = {'selected':…, 'picked_by':…, 'reason':…, 'round': 旧的最大轮次}` 给追溯用；重出停下时第 1–4 步自然让 default 指向新一轮。
7. `selected` 为 None 时 `status`、`deliver` 对 awaiting_pick 的任务不崩（`result_text` 已处理 None → "选中：无"），确认一遍，写进报告。
