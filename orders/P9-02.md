# 工单 P9-02：检测接入流程——检测蒙版局部重绘、面部裁切、瞳色采样、单主角计数、盲审缩图

先读 AGENTS.md（含补充禁令 4、5）、PROGRESS.md 决策 D10–D17、`reports/P9-01.md` 与 `orders/P9-01.md` 末尾监工结论（含监工定的检测阈值）。在现有代码上修改。

## 要做的事

1. **面部裁切改用检测**（D10）：审核、定妆、面部精修、IPAdapter 参考里所有"让视觉模型给面部 bbox"的地方，改为本机面部检测；检测不到脸时记录 `face_not_detected`（背影/远景属正常），不回退到视觉模型猜框。
2. **检测蒙版局部重绘**（D10，重新启用 P5 默认关闭的局部重绘）：区域来自检测（面部框、人物分割蒙版，或"主角以外的人物"蒙版），生成羽化蒙版上传 ComfyUI，走已有的局部重绘链路（保持长宽比、上下文边距、边界色差检查——P5-01b 已实现的部分沿用）。用途：
   - 面部问题 → 面部蒙版局部重绘（+ IPAdapter 定妆面部）。
   - 多出来的主角 → 去掉"非主体"那个人物的蒙版区域（正向提示词写背景，负向写人物）。
   修复对应表（配置）中重新启用这两条，其余保持 D6。
3. **瞳色/配饰颜色采样**（D11）：在面部裁切里定位眼部区域（通用做法，例如面部框内上半部分、排除肤色和发色的高饱和像素），采样主色，与 identity 锁定的瞳色 tag（颜色名 → 色相范围映射写配置）和定妆图采样结果比对，输出 `eye_color_sampled: ok / mismatch / not_visible` 及数值证据（色相、饱和度、像素数）。配饰同理只做"定妆图中存在的显著色块在当前面部附近是否存在"的粗检，拿不准就 not_visible。这是新的审核项，与视觉模型的 eye_color 并列记录，不替代它。
4. **单主角计数**（D15）：按监工在 P9-01 定的规则（写进配置）：主要脸 = 置信度 ≥0.6 且面积 ≥ 最大脸面积的 30%；主要人物 = 置信度 ≥0.5 且框面积比 ≥0.08，去掉同时包含另外两个人物框的大合并框；主体数 = max(主要脸数, 主要人物数)。P9-01 证据：人物分割会把相邻两人合成一个框（D1），但面部检测能分开；背景路人的脸和框都很小（D8）。分镜里声明了 `reflection`（镜子/玻璃倒影）的镜头，允许一个倒影；分镜允许的路人/局部入镜按 other_people 处理。输出 `protagonist_count` 与判定 `ok / duplicate / none_visible`，作为新的审核项。
5. **盲审缩图**（D13）：盲审前把每张图等比缩到配置的长边（例如 768px），日志记录缩放前后尺寸与哈希；盲审请求仍只含图片。
6. **每组耗时上限 60 分钟**（D12）：改配置，相关测试同步。
7. 离线测试覆盖以上各项；用 P9-01 的 14 张图做一次离线回放（不出图），输出新审核项在这些图上的结果。
