## 要做

1. **换回 / 换成的理由**。人选模式（任务 config 的 `human_review()` 为真）：`candidate == auto` 时理由为 `由{PICKERS[by]}看图换回候选{candidate}（程序默认）`；否则 `由{PICKERS[by]}看图换成候选{candidate}（程序默认候选{auto}）`。`result_text` 对应行人选模式写"由{who}换过：第 N 镜由{who}看图换成候选 K（程序默认候选 A）。"，去掉"看图复述是换之前那组图的"。审核器模式两处原样保留"审核器原选"。`auto` 的来源：V3-03 之后槽位里有 `auto_selected`，用它。
2. **reshoot `--by {user,agent}`**，默认 user，和 pick 一样：`agent.py` 加参数，传给 `candidates.reshoot(root, number, framing, angle, by=…)`；note 用 `WHO[by]`："第 N 镜由{用户|调用方}改为 X 重出（原 Y）。"；槽位记 `slot['reshoot_by'] = by`（V3-03 的 `before_reshoot` 里也带上）。
3. **prune**：
   - 新增一类 `drafts_dirs`：`PROJECT/drafts/cg-*` 里的空目录（listdir 为空；符号链接跳过；路径解析后仍在 `drafts/` 下才删），不看天数。输出 JSON 加 `"drafts_dirs": [{"path": …}]`，`--apply` 时 rmdir。`compile/`、`jobs/` 的规则不变。
   - `--days 0` 允许（`< 0` 才报错）；0 天的含义是"现在之前的都算"。
   - `prune --help` 的描述和 `agent.py` main 里那行 help 加上 drafts。
4. **review.md**：存在时照旧；不存在时这一节写"- 没有 review.md（这一组没有视觉模型审核）。manifest.json 记录每张图的提示词和种子。"
