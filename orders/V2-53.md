## 背景（监工已核实）

1. `face_refine._inspect` 用 `detect_faces(path)` 找脸，走 `config/detect.json` 的 imgsz 640；取置信度最高的一张，没有就是 `no_face`，长边 ≥ `max_face_px` 是 `not_needed`，否则 `pending`。
2. `detect.detect_faces(image, config=...)` 可以传入检测配置；`_detect` 把 `config['imgsz']` 交给模型；`load_detect_config()` 每次返回新的字典。
3. 主线 `jobs/cg-d7ecacac0a79/storycg_cg-d7ecacac0a79_shot01_a001.png`（第 1 镜候选 1，远景，主角很小）：640 下 0 张脸、0 个人体框；1280 下 1 张脸，长边约 38 像素，置信度 0.738。监工的子任务在 87 张图上比较过：1280 下其余图的脸数不变，人体框变差。所以只给找脸用 1280，人数检查不动。
4. `candidates.rank_key(audit, number)` 返回 `[第0级..第4级, minor, 编号]`，越小越好，逐级比较。通过筛选的候选第 0 级总是 0（人数不过和多余肢体都被筛掉了）。`pairwise.comparison_pool` 只比较 `rank[:4]` 和第一名相同的候选。
5. 候选审核里 `detection_items.detection.faces` 和 `.persons` 是 640 下的检测结果（检测器置信度 ≥ 0.25 的框）。

## 要做

1. **配置**：`config/default.json` 的 `face_refine` 一节加 `"fallback_imgsz": 1280`。任务配置的 `face_refine` 里没有这个键时（V2-50 以来的已有任务），不回退，行为和现在完全一样。
2. **找脸回退**（`face_refine._inspect`）：
   - 640 找到脸时完全照旧：只调一次 `detect_faces`，记录的字段和值都不变。
   - 640 没找到、配置里有 `fallback_imgsz` 时，用 `load_detect_config()` 的副本，把 `imgsz` 改成这个值，再调一次 `detect_faces`。找到了就按原来的规则判 `not_needed` 或 `pending`，记录里多一个键 `detect_imgsz`，值为回退用的尺寸。仍然没有就是 `no_face`。
   - 不改 `config/detect.json`，不改人数检查、审核、终审里的检测。
3. **降级**：一个候选同时满足下面两条，就在它的 rank 第 0 级加 1：
   - (a) 它的审核里 `detection_items.detection` 的 `faces` 和 `persons` 都为空；
   - (b) 它有面部精修记录，并且状态是 `no_face`。
   - 满足时 `candidates.json` 的 record 记 `nothing_detected: true`，manifest 的 `candidates` 记录也带上。不满足时不加这个键。
   - 不筛掉，`screen` 不变。没有面部精修记录（任务配置没有 `face_refine`）时不降级。
   - `rank_key` 加一个可选参数传入精修记录，默认不降级，旧的调用方式结果不变。
4. `LEVEL_NAMES[0]` 改成 `'count, extra body part or nothing detected (D29 level 0)'`。
5. **result.md**：选中的候选 `nothing_detected` 为真时，在"已知问题"里加一条，文字照抄：`第 {n} 镜选中的候选里，本机检测器没找到人，放大检测也没找到脸，主角可能很小或没画出来，请看图确认。` 没有这种情况时 result.md 一字不差。
