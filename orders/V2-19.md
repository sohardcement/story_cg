# 工单 V2-19：修图里整张重新出图时，负向提示词要和首轮出图一致

V2-18 的报告里指出：`repairs.repair` 在建修复 attempt 时传的是 `negative=None`（`src/storycg/repairs.py` 约第 177 行）。各修法的影响不同：

- seed 重抽：沿用原 attempt 的 workflow，负向提示词还在，不受影响；
- relayout：用改过的分镜整张重新出图，负向提示词只剩 workflow 的默认值。分镜拼出来的负向全部丢失，包括：
  - 固定负向（multiple girls、2girls、multiple views）；
  - 景别负向；
  - 场景里被排除的天气；
  - V2-18 新加的室内降水负向。
- instruction_edit、face_detail：走编辑或局部重绘流程，要你先查清它们的 workflow 是否用到负向提示词。

工作目录、写入范围、git 规则同 V2-10（AGENTS.md 第 8、9、10 条）。

## 要做

1. **查清现状**：
   - 列出每种修法实际提交的负向提示词，取已有任务的 attempt 记录（只读）。
   - 统计已有任务里 relayout 修复 attempt 的数量，以及它们缺了哪些负向 tag。
2. **修 relayout**：用改过的分镜，按首轮出图同一个函数（`assemble_prompt`）拼出的负向提示词出图。attempt 记录里要有完整的负向，以及 V2-18 的室内降水记录。
3. **其他修法**：instruction_edit 和 face_detail 的 workflow 如果确实用到负向提示词，就也按 `assemble_prompt` 补上；没用到就不改，在报告里写明。
4. 不改 seed 重抽的行为。

  - seed 重抽的 workflow 不变。
- 全量测试通过。
