# 工单 V2-04b：层级缓存改用 ComfyUI 报告的文件名和大小（D47 = b）

先读 `TASK-v2.md` §6 第 9 项、你自己的 `reports/V2-04.md`（层级缓存一节和"需要用户转派"），以及 AGENTS.md 补充禁令第 8、9 条。工作目录是 v2 工作树；写入范围和 git 规则按第 9 条执行。

## 背景

V2-04 的层级缓存要求用底模和角色 LoRA 的完整文件 SHA256 作键。但模型文件在 ComfyUI 主机上，这边读不到，所以缓存一直没有启用。

用户决定（D47 = b）：模型身份改用 **ComfyUI 报告的文件名和文件大小**。

ComfyUI 的 `GET /experiment/models/<folder>` 会返回每个文件的 name、size、modified。`comfy.py` 的 `list_model_files` 已经在调用这个接口，`model_metadata.py` 也在用它。

## 要求

1. **缓存键改为**：canonical 角色 tag + 底模 `{name, size}` + 角色 LoRA `{name, size}`（没有角色 LoRA 时为空）。
   - 不用 modified：复制文件会改变 modified，但内容不变。
   - 文件名和大小都取自当次运行时 `list_model_files` 的返回，不读本地文件路径。
2. **拿不到时不缓存**：接口失败、文件不在列表里、或 size 缺失时，这一次不读也不写缓存，照常重新判定层级，并在任务记录里写明原因。不能用别的值替代。
3. **默认启用**：删掉 V2-04 为完整文件哈希加的本地路径映射配置（`tier_cache.model_files`）和相应代码路径。
   - 缓存里**证据文件**的完整性校验（快照和比较记录的 sha256）保留不变，因为那些是本地文件。
4. **交付说明**：命中缓存时仍写"层级沿用缓存（日期）"。键里的文件名和大小写进任务记录，方便核对。
5. 缓存写入条件、证据校验、L3/L4 规则、模型变化后探针目录隔离等，都**按 V2-04 原样保留**，只是把"模型指纹"的来源换掉。

## 测试与验证

- **改写单元测试**：
  - 文件名变或大小变都会失效；
  - modified 变不失效；
  - 无 LoRA 时键为空；
  - 接口失败、缺 size、文件不在列表时不读不写缓存；
  - 证据损坏时拒绝命中。
- 全量测试通过；CLI `--help` 正常。
- **在线只读核对**：调用一次 `GET /experiment/models/checkpoints` 和 `/experiment/models/loras`，打印当前配置的底模，以及月城柳专用 LoRA 的 `{name, size}`，作为键的样例写进报告。
  - 这是只读查询，不出图、不调用视觉或分镜模型；
  - 注意网络可能丢包，失败可以退避重试只读查询。

## 产出
