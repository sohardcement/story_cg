## 要做

1. **互斥场景 tag 报错**（普通和 `--strict` 都是 error）：expand 段对每个 scene 的 tags 按 `EXCLUSIVE_TAGS` 查，命中 → `add_error(None, f'scenes.{name}.tags', f'互斥的场景 tag 同时出现：{a} 和 {b}', fix)`；fix 对每一对各写一句（如 indoors/outdoors："二选一：室内写 indoors 加地点（bedroom），室外写 outdoors 加地点（street、park）；廊下、阳台算 outdoors"）。`strict_warnings` 里那条 warning 去掉，不要两边都报。
2. **表外 action_tag 按 approx 处理**：expand 段，action_tag 不在 `measured_action_tags()` 且 fit 不是 approx 时：pop 掉，记 note rule `action_tag_unmeasured`，text "第 N 镜：action_tag X 不在「画得出」清单里，丢弃（意图只留在 action_note）"。在清单里的照旧走 `_action_tag_errors`。`--strict` 的 schema 枚举不变（strict 下先报 error）。
3. **spatial_relation 丢弃并记 rewrite**：写作者给了时 pop 掉，记 note rule `spatial_relation_dropped`，text "第 N 镜：spatial_relation 不是写作者字段，已丢弃，程序按 pose 补"；然后照旧 setdefault。
4. **缺 fit 记一条**：没写 fit 时按 exact，记 note rule `fit_defaulted`（"第 N 镜：fit 缺省，按 exact"）。`--strict` 下仍是 required，不变。
5. **三段错误一次报完**：expand 段有错时不立刻 raise；接着跑 fill_defaults、schema 校验，再跑 `_collect_errors`，三段的 errors 合并后一次 `raise BeatsError`。合并规则：按 (shot, field, problem) 去重；同一镜同一 field 在 expand 段已有错误时，后两段同 field 的不再加（避免占位引起的连锁错误）；顺序 expand、schema、collect。**镜数检查提前到 expand 段**（数原始 shots），这样它不依赖后面两段。schema 段有错导致 materialize 做不了时，collect 段跳过，报告里写明哪些 case 因此只报两段。某段抛的不是 BeatsError 的异常照旧向上抛。notes（rewrites）在 invalid 时本来不输出，不用改。
